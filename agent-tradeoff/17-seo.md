Work on `apps/rumortown/index.html`, a new `apps/rumortown/about.html` (second Vite entry), `apps/rumortown/public/` and `apps/rumortown/vite.config.ts`. Read `docs/how-it-works.md` (from task 16), `README.md`, `docs/launch.md` and the opening-card copy for the source text. No new dependencies.

On about.html: `FAQPage` with the six questions below.
