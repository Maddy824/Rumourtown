# Things only the owner can do

Local play and writing your own stories need no account or key. The API setup and paid evaluation items below are optional; they do not block the current game. Public hosting and package publication remain separate launch steps.

1. **Play-test locally.** `npm run dev` at the repo root, open the printed address on a laptop and on your phone (same Wi-Fi, use the Network address). Whisper "Tom stole bread" to Mira, run a day at 8×, open tags, open "Follow a rumor", scrub, copy the link, reload it. Write what felt wrong in `agent-tradeoff/reports/playtest.md` so Codex can tune it (give it the file as a task).
2. **Decide the two open design questions**: the village's setting and names (storybook-neutral as now, or a specific place), and the name "RumorTown". Both are data changes; tell Codex which files to change (`apps/rumortown/src/content/cast/`, `index.html` title, README).
3. **Cloudflare account**: create it, then `npx wrangler login`. Static game hosting needs no model credentials. Follow [deployment](../docs/deploy.md); configure Turnstile, signing and the four API secrets only for the optional interpreter. Keep `DEPLOY_OPTIONAL_API` unset until that service is needed, and validate staging traffic using [the capacity guide](../docs/scale.md).
4. **OpenRouter (optional, disabled by default)**: buy $10 of credit, keep auto top-up off, create two keys with credit limits: `rumortown-live` ($7) and `rumortown-dev` ($2). The live key goes into the Worker secret; the dev key into `apps/api/.dev.vars` as `OPENROUTER_API_KEY=...` (git-ignored) for local evals.
5. **Phone alerts and optional eval run**: complete [ntfy setup](../docs/credit-controls.md), save `USAGE_ALERT_URL` as a Worker secret and confirm device delivery before enabling `AI_ENABLED`. Keep production pacing at $0.019/day and lifetime live spend at $7. Then, for an explicitly enabled local evaluation, `npm run dev -w apps/api` in one terminal (Wrangler dev with `.dev.vars`), then the command in `apps/api/evals/run.ts`'s header. Keep the printed table; it goes in the README.
6. **GitHub**: repository created at https://github.com/Maddy824/Rumourtown; the controller prepares and pushes `build/village` at the owner's request. Set repository secrets CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID, and variables VITE_API_BASE_URL and VITE_TURNSTILE_SITE_KEY. When ready to launch, configure a release on `main` to match the deploy workflow; `build/village` is currently the development branch. The current default development branch is not a production deployment.
7. **Domain** (about $10 a year, auto-renew): point it at Cloudflare; set the root to the game and `api.` to the Worker; set the Worker's ALLOWED_ORIGIN var to the game's origin.
8. **npm**: create the `rumormind` package's trusted publisher link on npmjs.com (GitHub Actions, the publish workflow), then tag `rumormind@0.1.0` to publish.
9. **Launch**: record the GIF and the 15-second clip per `docs/launch.md`; post.
