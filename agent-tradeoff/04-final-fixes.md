# 04: Fix the final review's findings

Read `agent-tradeoff/reports/03-final-review.md`. Apply every Critical and Important finding, and the Minor ones it marks as blockers, in one pass. For each: the smallest change that resolves it, a covering test where the finding is about behaviour, and a line in `agent-tradeoff/reports/04-report.md` with the finding, the file and line changed, and the test. Run `npm run typecheck`, `npm test` and `npm run build`; commit per directory with messages starting `04:`. Then run the review once more in read-only mode (the command in `03-final-review.md`, output to `agent-tradeoff/reports/04-rereview.md`) scoped to the fix diff (`git diff <commit before fixes>..HEAD`), and record any residual findings in the report as parked, with a one-line reason each.
