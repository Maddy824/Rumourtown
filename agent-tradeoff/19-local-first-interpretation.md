# 19: Local-first interpretation, then free Workers AI, then OpenRouter

Owner direction: typed whispers should cost nothing wherever possible. Build three tiers: a deterministic interpreter in the browser, Workers AI in the owner's Cloudflare account (free daily allowance), and the existing capped OpenRouter path last. Read `apps/rumortown/src/net/` (whisperFlow, interpret), `apps/rumortown/src/content/cast/` (names, roles, voices), `apps/api/src/` (index.ts, prompt.ts, validate.ts, prices.ts, ledger.ts), `apps/api/evals/lies.json` (200 whispers with expected answers) and `docs/credit-controls.md`.

## A. Browser-side rule interpreter (apps/rumortown/src/net/local-interpreter.ts)
1. `interpretLocally(text, cast): LocalResult` where `LocalResult` is `{ claim: { kind, about, target?, object?, severity, valence }, confidence, evidence: string[] } | { unsupported: reason, confidence } | { unsure: true }`. Pure, synchronous, deterministic, no dependencies.
2. Subject resolution: match villager names (case-insensitive, possessives, common misspellings via a small edit-distance check), nicknames if the cast defines them, and role phrases from the dossiers ("the baker", "the miller's wife" via spouse links, "the innkeeper"). Two matches: the first mentioned is `about`, the second `target` when the kind takes one. No match: `unsupported: not-about-cast` if the text names a capitalised unknown person, else `unsure`.
3. Kind detection: a lexicon per taxonomy kind (stems and phrases, including slang the eval set uses), with negation handling ("never stole" → unsure), favourable kinds detected before harmful ones when both appear, and an object lexicon matching the Worker's allowlist (bread, flour, tools, coins, …). Severity from intensity words ("a little" → 1, "every"/"always" → 3, else 2).
4. Confidence: 0.9 when subject and kind are unambiguous, 0.7 when the kind matched one lexicon weakly, below 0.6 otherwise. Guard rails: protected-trait and sexual terms → `unsupported` locally without any network call; the same blocklist as the Worker's `moderation.ts` (copy the word list into a shared JSON under `apps/rumortown/src/net/` and have the Worker import the same file if the build allows; otherwise keep two identical lists with a test that they match).
5. Flow: in `whisperFlow`, run the local interpreter first. Confidence ≥ 0.75 → show the confirmation card immediately with the line "Understood locally" in small text, no network. Otherwise call the Worker as now. The player can always "Change it".
6. **Offline eval**: a vitest that runs the 200 eval items through the local interpreter and prints a table: in-scope accuracy (kind and about), abstention accuracy on out-of-scope items (must be 100%: no out-of-scope item may produce a claim), and the share of items that would have needed the Worker. Targets: ≥ 75% kind accuracy on items it answers, 0 false claims on out-of-scope, and record the real numbers in the report and in `README.md`.
