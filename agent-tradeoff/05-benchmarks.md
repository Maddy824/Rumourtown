# 05: Benchmarks

Create `bench/` at the repository root with a Node script (`node --experimental-strip-types bench/sim.ts`) that builds the real simulation from `apps/rumortown` modules (map, world, cast, claims, talk, engine) and measures game-minutes simulated per second for 24 villagers (the real cast) and for 60 villagers (duplicate background villagers with new ids and shifted schedules), over three full days each, reporting median and p95 of per-tick time and total wall time. Also measure `findPath` median over 1,000 random reachable pairs and `BeliefLedger.hear` median over 100,000 calls. Print a markdown table and write it to `bench/results.md` with the machine description (`os.cpus()[0].model`, Node version). Add `npm run bench` at the root. Do not add dependencies. Keep the script deterministic (seeded). Put the table in `README.md` under a "Benchmarks" heading with the date. Commit `bench/`, `package.json` and `README.md` with a message starting `05:`.
