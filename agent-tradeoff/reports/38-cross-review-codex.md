# Cross-review of the neural track

Reviewed [the independent neural design](../../docs/research/neural-track.md) (D) against [the earlier neural report](38-neural-codex.md) (C), 22 October 2026. Section and hypothesis numbers below refer to D unless stated otherwise. This is a design audit, not experimental evidence; neither draft nor any code was changed.

## A. Claims, formulas and fixes

1. **Emergence (§1):** $l^\star=\min\{l:\mathrm{AUROC}_l\ge .9\}$ is a valid operational threshold, provided an empty set returns N/A. It is not the first layer possessing knowledge, and a noisy single-layer crossing after searching all layers is fragile. Freeze the threshold on development roots, require persistence over three layers, report simultaneous root-bootstrap bands and threshold sensitivity, and confirm frozen layers on new roots. C's .80 threshold is also a convention, not a scientific correction to .90; use .80 primary with .75/.85/.90 sensitivity and report $l/L$.
2. **Labels and shortcuts (§1):** binary logistic regression only specifies $y_K,y_E$; use multinomial probes and macro one-vs-rest AUROC for bands/acts. Confidence is N/A for absent claims; entitlement should contrast known-permitted with known-forbidden. Fit regularisation/scalers inside root-group folds. Keep the question identical in ledger-present/absent pairs; hold out stories, aliases and wording. Question-only performance diagnoses shortcuts but is not a mathematical bound on contextual decoding. Add literal-membership, token-count and position controls: probes can read question templates, explicit confidence words, ledger length or fact position rather than integrate evidence. Public prompts must exclude evaluator labels.
3. **CKA (§1):** D names but does not define it. For identical rows and positions with column-centred $X,Y$, use $\mathrm{CKA}=\|X^\top Y\|_F^2/(\|X^\top X\|_F\|Y^\top Y\|_F)$; zero denominators are N/A. CKA is invariant to orthogonal rotations, whereas a fixed probe generally is not, so even CKA=1 can coexist with failed transfer. Large nuisance components can also hide changes in a small knowledge-relevant subspace. Include identical-checkpoint, permuted-row and sample-size controls. [CKA definition and invariances](https://proceedings.mlr.press/v97/kornblith19a/kornblith19a.pdf).
4. **H2/H3 (§1):** early-high/late-low CKA only localises representational change late; late blocks also compute representations, so this does not establish a changed readout. Stable refitted AUROC with leakage supports preserved linear accessibility, not intact causal use; falling AUROC shows lost linear accessibility, not erased information. Transfer both ways using frozen source scaling/intercept, report AUROC plus log loss, and compare with within-checkpoint refits. Transfer failure with recovered refits suggests changed coordinates. Hold positions/text fixed, then test steering rescue and matched-pair activation replacement; an intervention may still use an alternative route rather than the model's normal mechanism.
5. **Steering normalisation (§2):** D first says $d_l$ is normalised and scaled by $\sigma_l$, then adds $\alpha\sigma_ld_l$; this risks scaling twice and never defines “activation norm.” Write raw $\delta_l=\mathbb E[h_l\mid K=1]-\mathbb E[h_l\mid K=0]$, $v_l=\delta_l/\|\delta_l\|_2$, $s_l=\mathrm{SD}(v_l^\top h_l)$ on balanced fitting roots, and inject $\alpha s_lv_l$ once. Skip zero direction/scale. Use matched ledger-edit pairs; unmatched means mix knowledge with act, content, confidence and length. If a probe was fitted to standardised features, map its weights back by inverse feature scales before normalising. Orient on fitting data only.
6. **Steering layer and timing (§2):** readability need not coincide with causal leverage. Search a small development-only set around $l^\star$ plus middle/late controls, clip to valid blocks and retain an N/A fallback; freeze selection before confirmation. Specify post-block injection at the last prompt position and subsequent decode positions: injecting only after the first reply token is consumed misses its initial decision. Compare first-decision-only with sustained steering; rebuild caches per condition. Include $\alpha=0$, matched-norm random directions and unrelated-task/fluency controls. C lacks an explicit random-direction requirement; adopt it here. [CAA precedent](https://arxiv.org/abs/2312.06681).
7. **Frontier inference (§2):** overlapping intervals do not establish equivalence, a shared one-dimensional mechanism, or “no erosion by construction.” Frozen weights prevent parameter updates, not behavioural damage. Steering can change fluency, length, source accuracy, act completion or cause silence/errors. Report $F,U,Q,O,\mathcal L_K$, coverage and failures on all fixed opportunities, with blinded audits; $1-F$ is not leakage. Fit $\alpha(\mu)$ on development and test simultaneous equivalence margins on fresh roots/stories, including per-pair correctness. Coincident $(O,\mathcal L_K)$ points can conceal different $Q$ and error patterns. Call these operating curves; only nondominated points form an empirical frontier.
8. **Latent formula (§2):** $z=u+\beta K+\epsilon$ gives a logistic answer model only if $\epsilon$ has a specified logistic distribution. For fixed $u$, zero-location noise and scale $s>0$, $P(\mathrm{answer}\mid K)=\sigma(a+bK)$ with $a=(u-\theta)/s$, $b=\beta/s$. A constant additive intervention shifts $a$ only if its effect on $z$ is constant across prompts and $K$. Only $a,b$ are identified, not $u,\theta,\beta,s$ separately; fix scale and location conventions. With heterogeneous $u$, matched score distributions must remain fixed, and marginal answer probabilities generally are not this two-parameter logistic model.
9. **“Equal slopes … steering suffices” (§2):** under the restricted binary task where every known answer succeeds and every unknown answer leaks, $O=1-\sigma(a+b)$ and $\mathcal L_K=\sigma(a)$, hence $\operatorname{logit}(1-O)-\operatorname{logit}(\mathcal L_K)=b$. This is a falsifiable invariant, not a general theorem for the seven acts. Equal fitted $b$ is compatible with an intercept shift; it does not prove an intervention realises that shift, has sufficient range, or preserves answer quality. Test slope equivalence with uncertainty, prompt-level intervention interactions, the invariant and held-out mapped outcomes. C supplies the restricted derivation but its shared-latent assumptions also need these checks.
10. **LoRA grid (§3):** D's table has $6+6+2+1+1=16$ cells, not 14. It omits both-module top/bottom cells and leaves the readout budget unspecified. Merge to C's 18 factorial cells plus norm-only, two output-only ranks and the historical rank-8 attention reference: 22 runs, then four additional runs to bring two selected cells to three seeds each. Keep identical data, ordered batches, tokens, updates, optimiser and MLX scale across cells; equal updates alone do not equalise parameter capacity or optimisation. A linear adapter has $r(d_{in}+d_{out})$ parameters; assert actual tensor manifests rather than assuming square attention projections.
11. **Controls and H4 (§3):** define positive erosion $E=F_{base}-F_{cell}=-\Delta F$; H4 predicts positive association with $E$, negative with D's signed $\Delta F$. Use Kendall $\tau_b=(C_d-D_d)/\sqrt{(C_d+D_d+T_x)(C_d+D_d+T_y)}$, where $C_d,D_d$ are concordant/discordant cell pairs and $T_x,T_y$ ties only in one variable; report N/A if undefined. Recompute all cell scores and $\tau_b$ under one shared root resample. Standard independent-cell Kendall p-values are inappropriate: cells share prompts/base, MLP counts have many ties, and one training run supplies no run uncertainty. Pre-register within-depth/rank contrasts, multiplicity and a usefulness-saturation equivalence margin; repeat selected cells. Count is confounded with placement, total capacity and optimisation, so neither Kendall nor C's Spearman identifies an MLP-specific causal dose response. Use matched-budget follow-ups for that claim.
12. **MLX feasibility (§3):** installed MLX-LM 0.32.2 converts the final `num_layers` blocks; bottom-half needs explicit paths. Saved Qwen uses bias-free linears/RMSNorm, so the bias-and-norm cell is norm-only; do not invent biases or count quantisation offsets as trainable biases. A tied embedding/head must stay frozen on the input path: implement an output-only low-rank delta and declare separately whether final norm is trainable. Dense head tuning is a different, much larger control. Verified against installed `models/qwen3.py`, `tuner/utils.py`, `tuner/lora.py` and the existing training script; C already flags these constraints.
13. **Attention statistic (§4):** D's difference of $(A_D-A_L)$ between leaked/supported sentences is descriptive, not an attribution of contribution: values and downstream transformations matter. Measure query $j-1$ when predicting claim token $j$, and define sentence/head/layer aggregation. Report raw and per-span-token masses, separating target-matching facts from whole sections. Match fact identity, span length, distance, output position/history and claim length; use held-out head selection and simultaneous intervals or a frozen aggregate. Equal-length random spans alone do not control recency or semantic relevance. Supported/leaked subsets also differ in content and generation survival. [Limits of attention-weight explanations](https://aclanthology.org/N19-1357/).
14. **Masking interpretation (§4):** block distractor keys before softmax during prefill and decode, retaining positions and causal masks, and regenerate with a fresh cache; compare decode-only blocking to expose indirect prompt transport. Include no-op, position/length-matched random masks, equal-length content replacement and random-head ablations. Later distractor tokens can carry earlier distractor content, so full-section blocking is the primary removal. Evaluate all fixed opportunities, not only baseline leakers. Use $S_L=(\mathcal L_{mask}-\mathcal L_0)-\mathbb E_c(\mathcal L_{random,c}-\mathcal L_0)$ with corresponding $S_Q,S_U$ and audit. Reduced leakage beyond controls supports distractor dependence, not literal copying; content-swap tests should make leaked content track the replacement to strengthen that claim. A $Q$ drop does not establish “the same heads carry the ledger”: generic disruption or lost instruction processing also explains it.
15. **KL drift (§5):** the stated direction is coherent but asymmetric: $D_i=T_i^{-1}\sum_t\sum_vp_b(v\mid x,y^b_{<t})\log[p_b(v\mid\cdot)/p_t(v\mid\cdot)]$. Cache the base greedy continuation once and teacher-force its identical prefixes into both models; sum the full vocabulary with stable FP32 log-softmax, include generated EOS and report truncation/length. A chosen-token log-probability difference is not this KL. This is conditional divergence on greedy-base prefixes, not full sequence KL, which requires expectation over base-sampled histories. Tuned-prefix or reverse-KL sensitivity is useful but is a different estimand. C's phrase “symmetric drift magnitude” is wrong; replace with “unsigned divergence” without changing either draft here.
16. **Drift inference (§5):** regress signed paired $\Delta F_i\in\{-1,0,1\}$ on drift, adjusting act, knowledge/exposure and baseline length, with root/run uncertainty and story interactions. Large drift can improve behaviour, and tiny drift can flip a near-tied decision; association does not establish mediation. Compare all split rows first, not only tuned failures. Existing seed/story splits also change composition, and two story families cannot support population-wide story claims.
17. **Calibration (§6):** the .9/.7/.5/.25 mapping is stipulated, not a validated probability of correct assertion; formal bands prescribe language and permit faithfully held false beliefs. The proposed gap is therefore not standard ECE. Initial “I,” punctuation, whitespace, role style and shared multi-token prefixes make assertion/hedge first-token sets incomplete or overlapping; doubt also licenses denial. Freeze tokenizer-specific disjoint alternatives on development, report uncovered mass, and score complete phrases with a prefix trie at a controlled target-specific stem, separately from natural replies. For policy-ECE, let $q=P_A/(P_A+P_H+P_D)$ and $g=1$ when the formal rule warrants unqualified assertion; use fixed bins and $\sum_b(n_b/n)|\bar q_b-\bar g_b|$, alongside Brier score and band-wise natural-output confidence/source/act audits. This conditional alternative-set diagnostic also needs zero/low-coverage reporting and stem sensitivity, which C should make explicit. If retaining numeric band targets, label the result a nominal band-alignment gap, not truth calibration.

## B. What D adds to C

- No substantive experiment family is exclusive to D: C already proposes probes/CKA, steering/training comparisons, freezing, masking, drift and confidence diagnostics. D contributes a much clearer three-question spine, compact H1–H7 predictions and an accessible threshold/ROC explanation; use that structure in the merged main text.
- D explicitly proposes Kendall's tau; C specifies Spearman. Adopt tie-adjusted $\tau_b$ as the exploratory grid association, retain planned contrasts as stronger evidence, and avoid claiming that changing rank statistic repairs confounding. D's lighter grid is a useful cost-conscious screen, although its count and timing need correction.

## C. What C adds to D

- A measurement contract: effective-ledger overrides and public-input rendering, paired/null controls, root/story/wording isolation, fixed denominators and act macros, errors/coverage, crossed run/root uncertainty and weighted two-person oracle audits. These prevent question-reading, benchmark leakage and “safe because silent” artefacts.
- Exact extraction positions, fold/scaler rules, CKA formula and transfer interpretations; unambiguous steering units/timing, development-only layer selection, tuned-model rescue, explicit mixture weights and held-out equivalence tests. C's latent derivation states its binary-task restrictions rather than treating every frontier as a threshold classifier.
- A full grid with trainable counts, MLX placement/scaling/tied-head constraints; causal masking controls and token alignment; full-vocabulary base-prefix KL; a tokenizer-aware confidence diagnostic; fresh-story prerequisites and realistic separate machine/implementation budgets. Neither draft yet provides evidence for a unique circuit or deployment readiness.

## D. One merged experiment plan

Planning ranges for one M4 Max/36 GB, sequential model execution; no runtimes were measured here. Benchmark representative lengths and the actual cap first, then replace estimates. D's 9×3×440 sweep already means 11,880 generations for one checkpoint/direction; extra checkpoints, directions, random controls and repeats multiply that. Its six-hour grid estimate also understates its own cell count before evaluation. Use staged development screening and frozen confirmation rather than running every control on every layer.

| Order | Work and decision | Machine hours |
|---|---|---:|
| 0 | Lock/re-score exports; split roots and new story/wording families; freeze metrics/audit plan; validate prompts, spans, no-op logits/cache and throughput on 100 prompts | 0.5–1 |
| 1 | About 3,000 Qwen base/act/verifier prompt states; nested probes, CKA/transfer, base-prefix KL and band diagnostics; freeze emergence and candidate layers on development | 2–5 |
| 2 | Screen steering on 256 development prompts, then selected-layer nine-alpha curves on about 1,000 fresh probes, including tuned rescue/random-direction controls; 200–500 attention cases with staged causal masks/content swaps | 4–10 |
| 3 | Qwen 22-run factorial/control/reference grid plus four repeats; select cells on development; evaluate all cells on common probes, confirm repeated cells on untouched roots/stories | 13–26 |
| 4 | 3B residual mixture: three $\mu$ values × three seeds; two development-selected placements × three seeds; measure mapped steering/training outcomes at matched leakage budgets | 27.5–32.5 |
| 5 | 1B existing-checkpoint replication and selected 3B probe/steer/mask checks; crossed bootstrap, at least 500 distinct audited outputs and final inference | 4–8 |

Total: 51–83 machine hours, plus approximately 23–38 hours implementing/analysing the harness and separate human audit/story-authoring time; new 1B training is outside this plan. Step 4 assumes 15 runs × 90 minutes plus 5–10 evaluation hours, and reuses a run only if its data/update manifest matches exactly. Reprice or reduce prespecified screening work after the pilot, without reducing confirmation after inspecting its results. Grid associations remain exploratory; freeze practical margins, multiplicity, seed/run counts and selection rules before confirmation. No method clearing audited usefulness/leakage guards is a valid negative outcome.

## Five-line summary

- Adopt D's compact questions and hypotheses, with explicit operational definitions.
- Stable probes and matching curves support hypotheses; they do not identify a unique mechanism.
- Fix steering units, logistic assumptions, the 16-cell count, erosion sign, masking claims and calibration target.
- Run frozen diagnostics before the corrected grid and repeated 3B confirmation; budget 51–83 machine hours.
- Build a validated MLX harness, preserve both drafts, and audit useful completion alongside leakage.
